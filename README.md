# MaidsoulKitchen 1.21.1 NeoForge

## 内容介绍/Content

此项目是经 MaidsoulKitchen 原作者 Azumic 许可、面向 Minecraft 1.21.1 NeoForge 独立维护和发布的版本。最低需要 Touhou Little Maid 1.5.3。

0.2.0 beta 进一步跟进 MaidsoulKitchen 1.20.1 的烹饪设置 UI 与交互，完善 Kaleidoscope Cookery（KC）汤锅支持。保留烹饪寻路、中枢、DrinkBeer 啤酒桶、多层蒸笼和 Farmer's Delight 蘑菇群落等现有功能。

This project is an independently maintained and distributed Minecraft 1.21.1 NeoForge release, published with permission from the original MaidsoulKitchen author, Azumic. Touhou Little Maid 1.5.3 or newer is required.

Version 0.2.0 beta brings the cooking settings UI and interactions closer to MaidsoulKitchen 1.20.1 and improves Kaleidoscope Cookery (KC) stockpot support. Existing cooking pathfinding, Culinary Hub, DrinkBeer, multi-layer steamer, and Farmer's Delight mushroom-colony support are retained.

## 0.2.0 beta 更新 / What's new

- 跟进 MSK 1.20.1 的烹饪框架和气泡提示。
- 进一步跟进 1.20.1 烹饪设置界面，改进厨具选择、搜索、翻页、白名单/黑名单和设置同步后的显示；修复 Cloth 厨具开关保存。
- 完善 KC 汤锅的多锅轮换、补料、盖锅与成品盛取，支持复用锅上已有锅盖及使用女仆主手锅盖。
- 改进旧工作设置的安全读取与迁移；恢复原版浆果/水果识别和 L2 采收，修复不同女仆采收规则相互影响。
- 修复 YHC 发酵配方的瓶装成品图标及对应名称显示。

Cooking settings now follow the 1.20.1 UI more closely, with improved selection, search, paging, filter synchronization, and configuration saving. KC stockpots support multiple-pot rotation and lids already on the pot or held in the maid's main hand. This update also improves saved-setting handling, restores vanilla/L2 harvesting support, isolates each maid's harvesting rules, and fixes YHC fermentation result icons.

详细内容见 [更新日志](CHANGELOG.md)。联机时请同时更新客户端和服务端。

See the [changelog](CHANGELOG.md) for details. Update both the client and server when playing multiplayer.
