# MaidsoulKitchen 1.21.1 NeoForge

## 内容介绍/Content

此项目是经 MaidsoulKitchen 原作者 Azumic 许可、面向 Minecraft 1.21.1 NeoForge 独立维护和发布的版本。最低需要 Touhou Little Maid 1.5.3。

此次更新参照 MaidsoulKitchen 1.20.1 分支跟进了烹饪寻路与烹饪中枢设计，修复了 DrinkBeer 啤酒桶任务，并加入对 Kaleidoscope Cookery 多层蒸笼及 Farmer's Delight 蘑菇群落耕作的支持。

This project is an independently maintained and distributed Minecraft 1.21.1 NeoForge release, published with permission from the original MaidsoulKitchen author, Azumic. Touhou Little Maid 1.5.3 or newer is required.

This update follows the MaidsoulKitchen 1.20.1 implementation for cooking pathfinding and Culinary Hub configuration, fixes the DrinkBeer beer-barrel task, and adds support for Kaleidoscope Cookery multi-layer steamers and Farmer's Delight mushroom-colony farming.

## 计划功能/Planned Features

计划功能包括 EveryXHotpot 社交火锅兼容：女仆可以与玩家一起吃火锅、自动加水、涮肉、夹菜，甚至互相抢菜；以及“经验隙间”物品，用于让女仆定位兼容的经验存储方块并存入或取出经验。这些功能尚未包含在当前版本中。

Planned features include social EveryXHotpot compatibility, allowing maids to join hotpot meals, automatically add water, cook meat, pick dishes, and compete for food, plus an Experience Gap item that lets maids locate compatible experience-storage blocks and deposit or withdraw experience. These features are not included in the current release yet.
